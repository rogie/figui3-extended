# FigUI3 Extended

Editor and experimental Lab web components for
[FigUI3](https://github.com/rogie/figui3).

## Install

```sh
npm install @rogieking/figui3 @rogieking/figui3-extended
```

```js
import "@rogieking/figui3/fig.js";
import "@rogieking/figui3/fig.css";
import "@rogieking/figui3-extended/fig-editor.js";
import "@rogieking/figui3-extended/fig-editor.css";
```

Lab components are opt-in:

```js
import "@rogieking/figui3-extended/fig-lab.js";
import "@rogieking/figui3-extended/fig-lab.css";
```
